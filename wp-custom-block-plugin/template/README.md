# WordPress Custom Block Plugin Template

Bundled with the Cursor skill **`wp-custom-block-plugin`**.

## Scaffold a new plugin

```bash
bash ~/skills/wp-custom-block-plugin/scripts/scaffold.sh {plugin-slug} {target-parent-dir} [{first-block-slug}]
```

Example:

```bash
bash ~/skills/wp-custom-block-plugin/scripts/scaffold.sh my-blocks ./plugins hero-box
cd ./plugins/my-blocks
npm install
npm run build
```

## Manual copy

Copy this `template/` directory and follow the rename table in `../reference.md`.

## Do not include in copies

- `node_modules/` — run `npm install`
- `build/` — run `npm run build`
- `package-lock.json` — regenerated by `npm install`

## Features

- Multi-block auto-loading via `wp_register_block_types_from_metadata_collection()` + `--blocks-manifest`
- format-types entry (`src/format-types/`)
- Build diff cleanup (`scripts/restore-unchanged-builds.sh`)
- Stylelint config for SCSS

See `../SKILL.md` for the full workflow.
