# Skills

現在個人で使用している Agent Skills の共有リポジトリです。

## スキル一覧

| スキル | 用途 |
|--------|------|
| [wp-custom-block-plugin](./wp-custom-block-plugin/) | WordPress カスタムブロックプラグインの新規作成（複数ブロック自動読み込み、format-types 対応） |
| [wordpress-theme-scaffold](./wordpress-theme-scaffold/) | WordPress テーマの新規作成（Composer PSR-4、Vite + SCSS、pnpm） |
| [wordpress-theme-starter](./wordpress-theme-starter/) | WordPress テーマ完全版雛形（PHP + Vite/SCSS/JS、pnpm、IIFE） |
| [wordpress-theme-template](./wordpress-theme-template/) | WordPress テーマ PHP 雛形のコピー（CPT、REST API、ページルーティング等） |
| [frontend-dev-package](./frontend-dev-package/) | 静的 HTML 向け Vite + SCSS + JS 開発環境の雛形 |
| [docker-wordpress-compose](./docker-wordpress-compose/) | ローカル WordPress 開発用 Docker Compose の起動 |
| [scss-workflow](./scss-workflow/) | SCSS 開発ワークフロー（FLOCSS、Stylelint、DRY 方針） |
| [js-workflow](./js-workflow/) | Vite ベース JS のモジュール構成（MVC 風、クラスベース） |
| [css-coding-conventions](./css-coding-conventions/) | CSS / SCSS のコーディング規約 |
